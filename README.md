# TAKAFUL 2.0 — Approved for Development V7

هذه الحزمة جاهزة للرفع إلى GitHub وتشغيلها عبر GitHub Pages.

## الملفات
- `index.html` — النسخة الأونلاين الكاملة من مواصفة TAKAFUL 2.0 V7.
- `.nojekyll` — يمنع GitHub Pages من معالجة الموقع عبر Jekyll.

## النشر عبر GitHub Pages
1. أنشئ Repository جديدًا.
2. ارفع محتويات هذه الحزمة إلى الفرع `main`.
3. افتح: Settings → Pages.
4. اختر Deploy from a branch.
5. اختر `main` و `/root`.
6. احفظ الإعدادات.
